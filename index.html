기기에 저장하며 자동으로 서버에 전송하지 않는 정보: 진료 일정의 병원명·메모, 비용 기록, 첨부한 사진(병원 안내문·영수증), 난자·배아 숫자, 피검사(hCG) 수치, 주사 부위 기록, 정부 지원 횟수 카운터, 투약 용량·날짜별 용량 변경·투약 완료 기록. 사용자가 이 내용을 AI 정리용 텍스트에 직접 넣으면 2의 처리 대상이 되며, 직접 실행하는 내보내기는 아래 1-4와 같습니다. 첨부 사진은 두 기능 모두에 포함하지 않습니다.

1-1. 카메라·사진 접근

진료 일정과 비용 기록에 병원 안내문·영수증 사진을 붙일 수 있습니다. 이때만 카메라 또는 사진 선택기를 사용하며, 운영체제가 접근 권한을 요구하는 경우 사진을 붙이려고 직접 누르실 때 요청합니다.

  • 붙인 사진은 앱 전용 저장 공간에 복사되어 이 기기에만 남습니다.
  • 서버로 업로드하지 않고, 동반자에게도 전송하지 않으며, AI로 분석하지 않습니다. (영수증 금액 자동 인식 기능을 넣지 않은 이유가 이것입니다. 자동 인식을 하려면 사진이 기기를 떠나야 하기 때문입니다.)
  • 앱 안에서 사진을 삭제하거나 해당 일정·비용 기록을 삭제하면 사진 파일도 함께 지워집니다.
  • 앨범의 원본 사진에는 접근만 할 뿐 변경·삭제하지 않습니다.

1-2. 음성 인식 방식과 동의

기기 전용 음성 인식이 가능한 경우에는 음성을 기기 안에서만 글로 바꾸며 앱이 음성 파일을 저장하거나 전송하지 않습니다. 기기 전용 인식을 지원하지 않거나 사용할 수 없는 휴대폰·웹에서는 서비스 제공자가 음성을 처리할 수 있다는 설명과 "휴대폰 음성 인식 서비스로 글로 바꾸기" 버튼을 표시합니다. 사용자가 이 버튼을 직접 눌러 동의한 경우에만 휴대폰 또는 브라우저의 음성 인식 서비스를 사용하며, 기기 전용 인식 실패 후 자동으로 서비스 인식을 시작하지 않습니다.

이 경로에서는 Google·Apple 등 OS·기기 또는 브라우저의 음성 인식 서비스 제공자가 음성을 처리할 수 있으며 해당 제공자의 방침이 적용됩니다. 운영자는 음성 파일을 받지 않습니다. 동의 시각은 기기에만 저장하며 서버로 보내거나 백업에 넣지 않습니다. 동의하지 않아도 텍스트를 직접 입력해 기록할 수 있습니다.

1-3. 앱 안정성 진단 (Firebase Crashlytics)

오류 수정과 안정성 확인을 위해 릴리즈 앱에서만 Firebase Crashlytics를 사용합니다. 디버그·프로필·테스트·웹에서는 수집하지 않습니다. 비정상 종료 스택, 고정된 오류 분류, 오류 관련 앱·기기 상태, 기기 모델, OS·앱 버전, Crashlytics 설치 UUID, Firebase 설치 ID(FID), 세션 ID를 처리합니다. 함께 포함된 Firebase Sessions는 앱·기기 메타데이터, 네트워크 연결 유형, 앱이 포그라운드로 전환되어 세션이 시작된 시각 등 안정성 지표를 처리합니다.

건강 기록·UID·이메일은 진단에 포함하지 않습니다. 앱이 보내는 Dart 오류는 예외 원문·입력값·화면 문맥을 제외한 고정 분류와 코드 위치로 제한합니다. 사용자 식별자·커스텀 키·사용자 행동 로그를 추가하지 않으며 Google Analytics SDK는 사용하지 않습니다.

수탁자는 Google입니다. 이 진단 수집은 릴리즈 앱에서 필수이며 앱 안에서 끄는 설정은 없습니다. Crashlytics의 오류 스택과 관련 식별자는 90일 보관 후 운영·백업 시스템에서 삭제하는 절차를 시작합니다. 설치 식별자의 별도 보유 기준은 아래 국외 이전 고지를 참고하세요. (Firebase 공식 개인정보 안내)

1-4. 사용자가 직접 실행하는 내보내기·가져오기

기록 요약 공유는 투약 일정·용량, 진료, 현재 회차의 난자·배아·hCG, 최근 14일 투약 완료·부위 기록 등을 텍스트로 만들어 사용자가 고른 앱·저장소로 전달합니다. 병원명·진료 메모는 각각 직접 선택한 경우에만 요약에 포함합니다.

백업 JSON 내보내기·가져오기는 허용된 기기 기록(여정·지난 회차·체크리스트, 투약 일정·용량·완료·부위, 진료의 병원명·메모, 비용, 난자·배아·hCG, 지원 횟수·선택 지역, 음성 기록 텍스트·AI 결과, 알림 설정)을 파일로 옮깁니다. 사진·음성 파일·계정·동의·동반자 연결·초대코드는 포함하지 않습니다. 가져오면 현재 기기 기록을 파일 내용으로 바꾸며 기존 사진 연결은 해제됩니다. 항목별 공유 설정은 백업에 포함되므로, 동반자와 연결 중이면 다음 동기화부터 가져온 여정과 공유를 켠 예정 정보가 3의 범위에서 전달됩니다.

이 내보내기·가져오기 자체는 운영자 서버를 거치지 않습니다. 외부에 저장하거나 보낸 사본은 사용자가 관리하며, 앱에서 기록·계정을 삭제해도 외부 사본은 삭제되지 않습니다. 초대코드도 사용자가 직접 공유 버튼을 누르면 선택한 앱으로 전달할 수 있습니다.

2. AI 처리 위탁

"AI로 정리" 기능 사용 시 기록 텍스트·현재 시술 단계명이 당사 서버를 거쳐 Google Cloud Vertex AI(global)의 Gemini 모델로 전송되어 요약·구조화됩니다. 건강 기록은 민감정보이므로 처음 사용할 때 별도로 동의를 받으며(버튼 "동의하고 AI로 정리"), 동의 시각을 계정에 기록합니다. 동의하지 않으면 기록은 기기에만 저장되고 AI 정리는 쓰지 않을 수 있습니다. 처리 수탁자는 Google(Google Cloud)이며, 당사 서버는 서울 리전을 사용하지만 AI 처리는 특정 리전에 한정되지 않아 한국 밖 Google Cloud 시설에서 이루어질 수 있습니다. 광고 목적 사용은 없습니다.

Google Cloud 서비스별 약관의 학습 제한에 따라 Google은 고객의 사전 허락이나 지시 없이 고객 데이터를 AI·ML 모델의 학습·미세조정에 사용하지 않습니다. 공식 데이터 보관 안내에 따르면 기본 인메모리 캐시는 입력·출력·파생 데이터를 메모리에 보관하고 기록한 뒤 24시간 이내 삭제합니다. 남용 감시 안내에 따르면 해당 감시가 적용되는 계약에서는 정책 위반이 의심되어 추가 조사가 필요한 프롬프트를 로깅하고 최대 90일 보관하며 권한 있는 Google 직원이 검토할 수 있습니다. 이 로그는 모델 학습·미세조정에 사용하지 않으며, Google Cloud Master Agreement 계약 고객은 이 프롬프트 로깅에서 기본적으로 제외됩니다. AI 정리는 Google 검색 그라운딩(Grounding with Google Search)을 사용하지 않습니다.

2-1. 처리 위탁에 따른 국외 이전

개인정보 보호법 제28조의8의 고지 항목에 따라 안내합니다. 아래 서비스의 이전받는 자(수탁자)는 Google(각 서비스 계약에 따른 Google 법인)이며, 연락처는 Google 개인정보 문의 창구입니다. 전송은 서비스 이용 시 네트워크의 암호화된 연결을 통해 이루어집니다.

서비스국가·시기·항목·목적·기간·거부 방법과 효과
Firebase Authentication국가: 미국. 시기·방법: 가입·로그인·인증·계정 관리 시 SDK를 통한 암호화 전송. 항목·목적: 이메일·비밀번호·UID·인증 여부·로그인 방법, 접속 IP·사용자 에이전트를 계정 인증·관리·남용 방지에 사용하며, Google로 로그인한 경우 위 1의 Google 계정 정보도 포함됩니다. 기간: IP 로그는 수 주, 그 밖의 인증 정보는 계정 삭제 요청까지 보유하고 요청 후 운영·백업 시스템에서 180일 이내 삭제됩니다. 거부: 가입·로그인을 하지 않거나 계정 삭제를 요청할 수 있으며, 인증이 필수여서 앱 이용이 제한됩니다.
Firebase Crashlytics·Sessions·Installations국가: 미국 등 Google Cloud·Google 데이터센터 소재 국가. 시기·방법: 릴리즈 앱 실행·세션 시작·오류 발생 후 SDK를 통한 암호화 전송. 항목·목적: 위 1-3의 오류·기기·앱·세션 정보와 설치 식별자를 오류 진단·안정성 측정·설치 식별에 사용합니다. 기간: Crashlytics 오류 스택·관련 식별자는 90일 후 삭제 절차를 시작합니다. Firebase 설치 ID는 Google의 설치 ID 삭제 API 요청 전까지 보유하며 요청 후 180일 이내 운영·백업 시스템에서 삭제됩니다. Sessions만의 별도 보유기간은 공식 안내에서 확인되지 않습니다. 거부: 앱 내 진단 해제 설정은 없으며 릴리즈 앱 이용을 중단하여 이후 수집을 멈출 수 있습니다. 계정 삭제가 설치·진단 자료의 즉시 삭제를 뜻하지는 않습니다.

3. 동반자 공유 (선택, 별도 동의)

초대코드로 동반자와 연결하면 연결 시점에 양쪽 모두 별도 동의를 받습니다 — 코드를 보여주는 쪽은 "동의하고 내 코드 보기", 코드를 입력하는 쪽은 "동의하고 연결" 버튼이며, 각각의 동의 시각을 계정에 기록합니다. 동의 후 서로에게 공유되는 정보는 다음으로 한정됩니다.

  • 시술 유형·회차·현재 단계·주기 시작일, 동반자 역할의 미션 진행(체크한 미션의 번호 목록)
  • 본인이 항목별로 공유를 켠 경우에만: 투약 항목명·예정 시각·시작일·종료일·반복 간격(매일·격일), 다음 진료의 날짜·시각·구분
  • 본인이 직접 전송 버튼을 누른 브리핑 문장

공유되지 않는 것

  • 투약·당사자 체크리스트의 완료 여부는 전송되지 않습니다. 투약은 예정 시각과 기간·반복 간격만 받아 자기 기기에서 알림을 볼 뿐, 실제로 이행했는지는 알 수 없습니다. 위 동반자 역할의 미션 진행 정보와는 구분됩니다.
  • 투약 용량과 날짜별 용량 변경은 공유를 켜도 전송하지 않습니다.
  • 병원명과 메모는 공유를 켜도 전송하지 않습니다.
  • 피검사 결과, 비용, 난자·배아 숫자, 첨부한 사진 등 그 외 정보는 자동으로 공유되지 않습니다.

공유 항목은 각각 언제든 끌 수 있고, 연결 해제도 언제든 가능합니다.

위 완료 기록·병원명·메모 등의 미전송 고지는 동반자 자동 공유의 범위입니다. 본인이 기록 요약·백업 파일을 직접 보내는 경우에는 1-4의 범위를 확인하세요.
